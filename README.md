## About this entry

`main.py` paints a steaming fondant au chocolat from scratch with the Python
standard library alone: a cracked, cocoa-crusted top with a glossy molten
centre, sauce drips running down the sponge into a pool on a dark silver
plate, and three cocoa beans at the base. It renders at 2048x2048, box-filters
down to 1024x1024 for antialiasing, and writes `/output/entry.png`. It uses a
fixed seed, so every run writes the same bytes.
